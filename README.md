# 智能文本自动断行工具

一个基于 Python / Tkinter 的桌面小工具，把长文本按标点自动断成一行一行，行与行之间空一行隔开。采用深色主题，一个单元格放一段文本，结果以「大盒子包小盒子」的形式展示在右侧。

当前版本：**1.2.0**

## 功能特性

- **单元格式输入**：左侧每个单元格放一段文本，可添加、删除、重命名，并实时显示字数。
- **两种断行模式**
  - 📖 **句子完整优先**（默认）：以完整句子为单位分行，尽量不把一句话拆开；只有单句本身超过字数上限时，才退化为在逗号、顿号等处就近断行。
  - 📏 **贴近字符数优先**：在不超过上限的前提下，就近选任意标点（含逗号）断行，每行更饱满，但可能拆开长句。
- **可设置每行最大字符数**：默认 150，范围 10–2000。
- **批量处理**
  - 一次导入多个 TXT 文件，每个文件成为一个独立单元格（自动识别 UTF-8，失败时回退 GBK）。
  - 支持从 Google 表格 / Excel 一键粘贴：复制的每个表格单元格对应软件里的一个单元格，数量不够会自动新增。
- **便捷操作**
  - 单个单元格「清理换行」，或一键清理全部。
  - 一键全部断行、一键复制全部结果、单个结果单独复制。
  - 右侧结果可以直接手动编辑，导出和复制时读取的是编辑后的内容。
- **导出**：单个结果直接另存为；多个结果可选「分别保存为独立文件」或「合并为一个 TXT」。
- **其他**：惯性平滑滚动；鼠标悬停在文本框内时，普通滚轮滚动整个列表，按住 Ctrl 再滚动才滚动文本框自身。

## 使用方法
基本流程：

1. 在左侧单元格里粘贴或输入文本；也可以点「导入文件为单元格」或「一键粘贴(Google表格)」。
2. 在底部设置「每行最大字符数」，并选择断行模式。
3. 点击「⚡ 一键全部断行」，结果显示在右侧。
4. 需要时直接在结果里修改，然后复制或导出。

### 按钮说明

| 按钮 | 作用 |
|---|---|
| ➕ 添加单元格 | 在左侧追加一个空单元格 |
| 📂 导入文件为单元格 | 多选 TXT 文件，每个文件一个单元格，文件名作为标题 |
| 🧹 清理所有换行 | 去掉所有单元格里的硬回车；两侧都是英文字母或数字时保留一个空格，避免单词粘连 |
| 🗑️ 清空全部 | 清空左侧所有单元格和右侧结果（会先确认） |
| 📥 一键粘贴(Google表格) | 读取剪贴板里的表格内容，依次填入单元格（会覆盖对应位置的原有内容，先确认） |
| 📋 复制全部结果 | 把所有结果用分隔线串联后复制到剪贴板 |
| 💾 批量/合并导出... | 导出结果为 TXT |

## 断行规则

- 断行只发生在标点之后，紧跟在标点后面的引号、括号会留在行末，不会和标点分离。
- 句子结束标点：`。！？…!?.`
- 次级停顿标点（用于拆分超长句）：`，、；：,;:—~`
- 如果一段文字里完全没有可用的标点，会优先在空格处断开，实在没有再按字数硬切，保证每行都不超过设定上限。
- 原文里的空行会被去掉，输出中每一行之间固定空一行。

## 导出文件说明

- **批量导出**：每个单元格保存为 `标题_断行.txt`。
  - 标题里的非法字符会被替换为 `_`，文件名最长 80 个字符。
  - 标题重名时自动追加序号，不会互相覆盖。
  - 目标文件夹里已有同名文件时会被直接覆盖。
  - 个别文件写入失败时，完成提示里会列出失败原因。
- **合并导出**：所有结果写入同一个 TXT，每段前有 `====================【标题】====================` 分隔线。
- 所有文件均以 UTF-8 编码保存。

## 使用限制

- 导入的单个文件不能超过 20 MB，超过会被跳过并提示。
- 「一键粘贴」时，单个表格单元格超过 131072 个字符会解析失败，需要拆开后再粘贴。
- 一次粘贴的单元格数量没有上限，几千个会让界面变卡。
